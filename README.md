# 48 Leis do Poder

Projeto da DIO sobre o livro **As 48 Leis do Poder**, de Robert Greene, utilizando o NotebookLM como ferramenta de estudo.

## Objetivo
- Conhecer as principais ideias do livro.
- Organizar o conteúdo de forma simples.
- Utilizar IA para resumir e revisar o assunto.
- Desenvolver uma análise crítica sobre as leis.

## Estrutura
- `fontes.md` — fontes utilizadas.
- `resumo.md` — resumo do tema.
- `glossario.md` — principais conceitos.
- `prompts.md` — prompts utilizados no NotebookLM.
