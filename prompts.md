# Prompts utilizados no NotebookLM

### Prompt 1
> Resuma as principais ideias das 48 Leis do Poder usando uma linguagem simples.

### Prompt 2
> Explique uma das leis com um exemplo do cotidiano.

### Prompt 3
> Quais são os riscos e os limites éticos dessa estratégia?

### Prompt 4
> Crie perguntas para revisar o conteúdo estudado.

## O que aprendi

O uso de prompts mais específicos ajudou a obter respostas mais organizadas e úteis para o estudo. Também foi importante conferir as respostas com as fontes.
